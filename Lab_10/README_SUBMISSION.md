# Lab 10 — Variant 2: Book Catalog

This folder contains the production-oriented Lab 10 project for variant 2 (book catalog).

## Structure
- `src/book_catalog/` — application package
- `tests/` — automated tests
- `pyproject.toml` — project metadata and development tools
- `Dockerfile` — container build
- `.github/workflows/ci.yml` — CI pipeline
- `REPORT.md` and `REPORT.docx` — lab report
- `dist/` — built wheel and source distribution
- `previous_labs/` — ZIP archives of the original Labs 5–9 from the provided repository

Previous laboratory archives are kept as separate ZIP files to preserve their original directory structures while keeping the number of files directly in this submission manageable for GitHub's web uploader. Generated caches, bytecode, and local database artifacts are excluded.
