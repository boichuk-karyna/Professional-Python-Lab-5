# Звіт до лабораторної роботи №10

**Тема:** Production Python: Docker, CI/CD та захист проєкту.  
**Варіант 2:** система обліку книг.  
**Виконала:** Бойчук Карина.

## Мета
Підготувати Python-проєкт до відтворюваного запуску: оформити пакет, винести конфігурацію в environment variables, додати REST API, автоматичні тести, перевірки якості коду, збірку дистрибутивів, Docker та GitHub Actions.

## Предметна функціональність
Система дозволяє додавати книги (назва, автор, рік видання, кількість сторінок), переглядати каталог, фільтрувати за автором і роком, переглядати авторів та їхні книги, знаходити найбільшу книгу й обчислювати середню кількість сторінок. Дані зберігаються в SQLite.

## Production-підготовка
- Пакет збирається через `pyproject.toml` у формати wheel та sdist.
- Налаштування читаються зі змінних середовища; `.env` виключений із Git.
- Dockerfile використовує slim-образ і непривілейованого користувача, налаштовано health check.
- GitHub Actions запускає Ruff, форматування, mypy, pytest, package build і Docker build.
- README містить інструкції встановлення, запуску, API та контейнеризації.

## Перевірка
Запуск локальних перевірок:

```bash
python -m pip install -e ".[dev]"
ruff check .
ruff format --check .
mypy src
pytest -v --cov=book_catalog --cov-report=term-missing
python -m build
```

## Висновок
У роботі підготовлено production-oriented версію системи обліку книг. Проєкт має REST API, збереження даних у SQLite, конфігурацію через environment variables, тести, інструменти контролю якості, пакування, Dockerfile та CI pipeline. Це спрощує повторний запуск і автоматичну перевірку змін.
