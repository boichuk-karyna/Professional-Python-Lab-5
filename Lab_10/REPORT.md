# Звіт — лабораторна робота №10

**Тема:** Production Python: Docker, CI/CD та захист проєкту  
**Варіант:** 2 — система обліку книг

## Мета
Підготувати попередній проєкт каталогу книг до production-oriented використання: оформити пакет, конфігурацію через environment variables, контейнеризацію, автоматичні перевірки та документацію.

## Предметна область
Книга містить назву, автора, рік видання, кількість сторінок та необов'язковий ISBN. Застосунок підтримує створення, перегляд, зміну й видалення книг, перегляд авторів, пошук/фільтрацію, статистику та REST API.

## Виконані завдання
1. Збережено `src`-layout; код API попередньої лабораторної перенесено до пакета `book_manager`.
2. Оформлено `pyproject.toml` з metadata, залежностями та dev-залежностями.
3. Налаштовано створення wheel і sdist.
4. Конфігурація БД, середовища та логування задається через `DATABASE_URL`, `APP_ENV`/`ENVIRONMENT` і `LOG_LEVEL`.
5. Додано `.env.example`; `.env`, локальна база та build artifacts виключені через `.gitignore`.
6. Додано `Dockerfile`, `.dockerignore`, persistent volume та Docker `HEALTHCHECK`.
7. Додано GitHub Actions workflow для Ruff, mypy, pytest, package build і Docker build.
8. Оновлено README з інструкціями встановлення, запуску, конфігурації, API, тестів і Docker.
9. Збережено SQLAlchemy persistence layer та REST endpoints із попередньої роботи. Запити статистики виконуються SQL aggregate-функціями; передбачені індекси, фільтрація, пагінація та сортування.

## Перевірка
Під час перевірки у доступному середовищі виконано тести: **20 passed**. Wheel створено локально. Створення sdist також перевірено через setuptools build backend.

У поточному середовищі не вдалося запустити Ruff, mypy та Docker: ці інструменти не встановлені, а завантаження пакетів недоступне через мережеві обмеження. У репозиторії налаштовано GitHub Actions, де ці перевірки виконуватимуться після push.

## Висновок
Проєкт каталогу книг підготовлено до пакування та контейнеризованого запуску. Додано керування конфігурацією через змінні середовища, правила виключення secrets, документацію й CI pipeline. Автоматичні тести пройшли успішно в доступному середовищі.
