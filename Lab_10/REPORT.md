# Звіт — лабораторна робота №10

**Тема:** Production Python: Docker, CI/CD та пакування проєкту.  
**Варіант:** 2 — система обліку книг.

## Мета
Підготувати наявний проєкт обліку книг до відтворюваного запуску: оформити його як Python-пакет, керувати конфігурацією через змінні середовища, підготувати Dockerfile, автоматичні перевірки та документацію.

## Виконано
1. Збережено предметну область книг і авторів та REST API попередньої лабораторної роботи.
2. Налаштовано `pyproject.toml`, метадані пакета, залежності й команду запуску.
3. Додано `.env.example`; `.env`, локальна БД та кеші виключені через `.gitignore`.
4. Додано Dockerfile із непривілейованим користувачем, volume для SQLite та health check.
5. Налаштовано GitHub Actions: Ruff, форматування, mypy, pytest/coverage, build пакета і Docker image.
6. Описано запуск, конфігурацію, API, тести, пакування й демонстрацію у README.

## Перевірка
Команди для запуску перевірок:

```bash
python -m pip install -e ".[dev]"
ruff check src tests
ruff format --check src tests
mypy src
pytest --cov=book_manager --cov-branch --cov-report=term-missing
python -m build
docker build -t book-manager-lab10 .
```

Результати потрібно зафіксувати після виконання команд у власному середовищі. GitHub Actions виконує ці перевірки автоматично після push.

## Висновок
У роботі підготовлено проєкт обліку книг до пакування та запуску в контейнері. Додано конфігурацію через змінні середовища, інструкції використання, автоматичні тести й CI pipeline. Це робить запуск і перевірку проєкту більш відтворюваними.
