Лабораторна робота №7 — Дискретне перетворення Фур'є

Запуск:
1. Встановіть Python 3.10 або новіший.
2. Відкрийте термінал у папці проєкту.
3. Виконайте: py -m pip install -r requirements.txt
4. Запустіть: py lab7_dpf.py

Програма виводить похибку відновлення та зберігає чотири окремі графіки й
загальний рисунок у папці results.

Модельний сигнал відповідає прикладу в методичці:
x[n] = 3*sin(n/5) + 3*sin(n/6), N = 1000.

Примітка: методичка містить Python-код, тому основний виконуваний файл — .py.
Якщо викладач справді вимагає Windows .exe, його можна зібрати окремо через PyInstaller.
